# Setup

Paket ini membuat profil GitHub `muhrafi-fsdev` bergaya developer command center:

- hero SVG dark/light
- GitHub streak
- statistics dan top languages
- contribution snake
- project cards yang diperbarui otomatis
- badge LinkedIn, Instagram, email, dan portfolio

## Workflow permission

Buka:

`Settings -> Actions -> General -> Workflow permissions`

Pilih:

`Read and write permissions`

Setelah paket di-push, jalankan workflow:

- Generate Projects Panel
- Generate Contribution Snake
